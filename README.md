# Edit Lock Indicator

여러 사용자가 **동기화 프로그램(Syncthing, Google Drive, OneDrive, 네트워크 공유 폴더,
Obsidian Sync 등)**으로 하나의 보관함(vault)을 공유해서 쓸 때, 다른 사용자가 지금
편집 중인 파일을 알려주는 옵시디언 플러그인입니다.

## 이게 뭘 해결하나요?

옵시디언은 원래 실시간 협업 기능이 없어서, 두 사람이 같은 노트를 동시에 고치면
동기화 프로그램이 "충돌 사본(conflict copy)"을 만들어버립니다. 이 플러그인은 완전한
동시편집(구글독스 같은)은 아니지만, **"이 파일 지금 누가 보고 있다"**는 것을
미리 알려줘서 충돌을 예방합니다.

- 다른 사람이 편집 중인 파일을 열면 상단에 경고 배너가 뜹니다.
- 하단 상태 표시줄에 잠금 상태가 표시됩니다.
- 파일 탐색기에 🔒 배지가 붙습니다.
- 그 사람이 파일을 닫거나 옵시디언을 끄면 자동으로 잠금이 풀립니다.
- 비정상 종료 등으로 잠금이 안 풀리면, 설정된 시간(기본 25초) 후 자동 만료됩니다.

## ⚠️ 중요: 반드시 필요한 전제 조건

이 플러그인은 자체적으로 인터넷 통신을 하지 않습니다. 보관함 폴더 안에
`_locks/edit-locks.json`이라는 아주 작은 파일을 만들어서 읽고 쓸 뿐입니다.
**이 파일이 다른 사용자의 컴퓨터로 실제로 전달되려면, 여러분이 이미 쓰고 있는
동기화 방법(Syncthing, Google Drive 앱, OneDrive, Dropbox, 회사 NAS 등)으로
보관함 전체가 동기화되고 있어야 합니다.** 즉 "동시에 여러 명이 같은 보관함 폴더를
편집"할 수 있는 환경이 이미 갖춰져 있다는 전제 하에 동작합니다.

또한 이것은 **강제 잠금이 아니라 경고 표시**입니다. 실제로 편집을 막지는 않으며,
동기화 지연(몇 초~몇 분)이 있는 경우 완벽하게 실시간으로 보장되지는 않습니다.

## 설치 방법 (수동 설치)

1. 옵시디언 설정 → `커뮤니티 플러그인` → `제한 모드 끄기(Turn off restricted mode)`
2. 이 폴더(`edit-lock-indicator`) 전체를 보관함의 다음 경로에 복사합니다.
   ```
   <보관함 경로>/.obsidian/plugins/edit-lock-indicator/
   ```
   (`.obsidian` 폴더가 안 보이면 숨김 폴더 표시를 켜세요.)
3. 옵시디언을 다시 시작하거나 새로고침합니다.
4. 설정 → `커뮤니티 플러그인` 목록에서 **Edit Lock Indicator**를 찾아 켭니다(Enable).
5. 함께 쓰는 **모든 사용자**의 컴퓨터에 같은 방식으로 설치하고 켜야 합니다.
6. (권장) `.obsidian/plugins` 폴더가 동기화 프로그램에서 제외(ignore)되어 있지 않은지
   확인하세요. 플러그인 자체는 각자 설치해도 되지만, `_locks` 폴더는 반드시
   동기화 대상에 포함되어야 합니다.

## 설정 항목

- **내 표시 이름 / 색상**: 다른 사용자에게 보여질 이름과 배너 색상.
  ⚠️ 이 값은 **이 컴퓨터의 로컬 저장소(localStorage)** 에만 저장되고, 보관함
  안에는 저장되지 않습니다. 반드시 **각 사용자가 자기 컴퓨터에서 직접** 이름을
  설정해야 합니다. (아래 "왜 이렇게 만들었나" 참고)
- **잠금 정보 저장 폴더**: 기본값 `_locks` (보관함 루트에 생성됨)
- **동기화 주기**: 몇 초마다 잠금 정보를 갱신할지 (기본 5초)
- **잠금 만료 시간**: 갱신이 끊긴 후 몇 초 뒤 자동으로 풀지 (기본 25초, 동기화
  주기보다 넉넉하게 3~5배 이상으로 설정 권장)
- **탐색기 배지 표시**: 파일 목록에 🔒 아이콘 표시 여부

## 비상 상황: 잠금이 안 풀릴 때

상대방이 크래시 등으로 옵시디언을 강제 종료해서 잠금이 안 풀리는 경우:
- 기본적으로 25초 후 자동 만료되어 풀립니다.
- 급하면 명령 팔레트(Cmd/Ctrl+P)에서 `현재 파일 잠금 강제 해제`를 실행하거나,
  설정 화면의 "강제 해제" 버튼을 누르세요.


## 왜 사용자 이름/ID를 보관함이 아니라 로컬에 저장하나요?

옵시디언 플러그인 설정은 보통 `.obsidian/plugins/<플러그인id>/data.json`에
저장됩니다. 그런데 이 경로는 **보관함 안**이라서, 보관함이 동기화되고 있다면
이 파일도 함께 동기화됩니다. 만약 사용자 이름/ID를 여기에 저장했다면, A가
설정을 바꿀 때마다 그 `data.json`이 B의 컴퓨터로 동기화되어 B의 이름/ID까지
덮어써버리는 문제가 생깁니다(마지막에 동기화된 사람의 정보로 모두가 통일되어
버려서, 서로 다른 사용자를 구분할 수 없게 됩니다).

그래서 이 플러그인은 **사용자 이름/ID/색상만 예외적으로 `localStorage`
(브라우저/Electron의 기기 로컬 저장소, 보관함과 무관하고 동기화되지 않음)에
저장**합니다. 반대로 동기 주기, 만료 시간처럼 "다 같이 똑같이 맞춰도 되는"
공용 설정은 그대로 보관함(data.json)에 저장해서 편의를 유지했습니다.

## 한계 (알아두세요)

- 진짜 실시간 동시편집(OT/CRDT 기반)은 아닙니다. 어디까지나 "경고 표시"입니다.
- 동기화 프로그램의 전파 속도에 따라 몇 초~몇 분의 지연이 있을 수 있습니다.
- 두 사람이 거의 동시에 같은 파일을 열면 아주 짧은 순간 서로 잠금을 못 볼 수도
  있습니다(레이스 컨디션). 완벽한 락이 필요한 팀 협업이라면 Obsidian Sync 같은
  전용 서비스나 실시간 협업 플러그인(예: Relay 등)을 고려하세요.
